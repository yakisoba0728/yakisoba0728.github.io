## 한 줄 소개
고가 GPU 한 장을 메모리 단위로 나눠 사용자별 격리 샌드박스로 빌려주는 GPU 대여 플랫폼의 컨트롤 플레인입니다. k3s와 HAMi 위에서 동작합니다.

## 아키텍처
- **컨트롤 플레인(NestJS)** — 인증, GPU 인벤토리, 샌드박스, reconciler, 게이트웨이, SSH 모듈
- **원하는 상태 저장소** — PostgreSQL(Prisma)
- **Kubernetes 어댑터** — 샌드박스마다 Pod, PVC, Service, Traefik IngressRoute 생성
- **SSH 게이트웨이** — 외부 SSH 접속을 컨테이너 셸로 연결

## 동작 흐름
1. 사용자가 로그인해 JWT를 받습니다.
2. 이미지, GPU 메모리(MiB), GPU 코어 비율, CPU·메모리를 지정해 샌드박스 생성을 요청합니다.
3. 원하는 상태가 Running으로 저장됩니다.
4. reconciler가 주기적으로 실제 클러스터 상태와 비교해 리소스를 만듭니다(Pending → Provisioning → Running).
5. 사용자는 토큰 URL로 웹에 접속하거나 등록한 공개키로 SSH 접속합니다.
6. 정지하면 Pod를 지워 GPU를 즉시 반납하고, PVC는 남겨 재개할 때 다시 연결합니다.

## 핵심 기능
- JWT 인증, 관리자·사용자 역할, SSH 공개키 등록
- HAMi 메트릭 기반 동적 GPU 인벤토리
- GPU 메모리 하드 분할
- 샌드박스 생성·정지·재개·삭제, 사용자별 영속 볼륨
- 이미지 레지스트리 허용 목록과 digest 고정

## 기술적 포인트
- **실기 검증**: 실제 H100에서 GPU 메모리 분할이 하드 격리로 동작함을 확인. 코어 비율은 소프트 공유임을 문서화
- **보안**: PodSecurity baseline, 사용자당 실행 샌드박스 1개 제한, 필수 비밀값이 없으면 기동 중단
- **테스트**: 210여 개

## 한 줄 소개
KORAIL 앱의 비공개 모바일 API를 역공학해 Python에서 사용할 수 있도록 만든 typed client library입니다.

열차 조회, 좌석, 승차권·예약·마일리지 조회를 지원하고 예약·결제·환불 같은 상태 변경은 명시적인 `MutationConsent`와 기본 `dry_run`을 통과해야만 전송되도록 설계했습니다.

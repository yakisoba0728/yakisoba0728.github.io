## 한 줄 소개
Claude·Codex·z.ai 모델 여러 개를 Docker 샌드박스에서 병렬로 돌려 CTF 문제를 함께 푸는 협업형 에이전트입니다. 터미널 대시보드(TUI)로 진행 상황을 봅니다.

## 아키텍처
- **CLI** — `ctf-solve`(실행), `ctf-msg`(실행 중 힌트 주입)
- **ChallengeSwarm** — 공급자별 solver N개를 띄우고 solver마다 Docker 샌드박스 하나를 연결
- **공급자 연결** — Claude Messages API, Codex app-server(JSON-RPC), z.ai REST
- **협업 계층** — 메시지 버스, 이벤트 버스, 선택적 coordinator 에이전트
- **안전장치** — 루프 감지, 비용 추적, circuit breaker

## 동작 흐름
1. 설정과 문제 입력을 검증하고 Docker 상태를 확인합니다.
2. solver마다 컨테이너를 만들고, 문제 파일은 읽기 전용, 작업 폴더는 쓰기 가능으로 연결합니다.
3. solver들이 셸·파일·웹 요청·이미지 보기 같은 도구를 병렬로 실행합니다.
4. 5단계마다 발견한 내용을 공유하고, coordinator가 막힌 solver에 방향을 제시합니다. 사용자도 힌트를 넣을 수 있습니다.
5. 처음으로 유효한 플래그를 낸 solver가 이기고 나머지는 취소됩니다. 시간·단계·비용 상한에 걸려도 종료합니다.
6. 풀이 과정 문서를 만들고 세션을 저장(이어서 실행 가능)한 뒤 컨테이너를 정리합니다.

## 기술적 포인트
- **샌드박스 하드닝**: 모든 capability를 뺀 뒤 필요한 것만 추가, `no-new-privileges`, 프로세스 수·메모리·CPU 제한
- **SSRF 방어**: 웹 요청 도구가 DNS 해석 후 사설·루프백 주소를 차단
- **오탐 방지**: 정규식으로만 찾은 플래그는 후보로만 취급하고, 오답이 이어지면 대기 시간을 늘림
- **루프 감지**: 같은 호출이 3번 반복되면 경고, 5번이면 강제 중단
- **검증**: 테스트 210여 개, 외부 코드 리뷰 두 차례의 지적 사항 반영

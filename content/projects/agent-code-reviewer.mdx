## 문제
PR이 쌓일수록 리뷰가 병목이 되고, 사소한 컨벤션·버그가 자주 새어 나갔습니다.

## 접근
GitHub Webhook으로 PR diff를 받아 변경 의도를 요약하고 리스크를 표시하는 리뷰 봇을 만들었습니다. 스펙과 가드레일을 프롬프트에 고정해 일관된 리뷰를 유도했습니다.

## 결과
1차 리뷰 시간을 크게 줄이고, 머지 전에 사소한 이슈를 자동으로 잡아냈습니다.

## 한 줄 소개
Claude, Codex, Gemini, GitHub Copilot, Cursor, z.ai 6개 AI 코딩 도구의 실제 구독 사용량(5시간 창, 주간 한도, 리셋 시각)을 메뉴바와 대시보드에서 확인하는 Tauri 데스크톱 앱입니다.

## 아키텍처
- **React UI** — 대시보드와 설정 화면, IPC로만 Rust 코어와 통신
- **Rust 코어**
  - `providers` — `ProviderApi` trait와 공급자 6개 구현
  - `scheduler` — 주기적 수집 루프
  - `secrets` — 각 CLI가 Keychain·Credential Manager·JSON·SQLite에 저장한 인증 정보 읽기
  - `oauth` — PKCE와 localhost 콜백 서버
  - `store` · `config` · `http`

## 동작 흐름
1. 각 CLI가 로컬에 저장한 인증 정보를 자동으로 찾습니다. 없으면 앱에서 키를 붙여넣거나 OAuth로 로그인합니다.
2. 스케줄러가 기본 5분(최소 30초) 간격으로 모든 공급자를 병렬 호출합니다. 한 곳이 실패해도 그 공급자만 연결 끊김으로 표시합니다.
3. 401이 오면 토큰을 스스로 갱신하고 갱신된 토큰을 원래 파일에 다시 씁니다. 429는 실제 한도 신호로 보고 갱신하지 않습니다.
4. 토큰을 가린 사용량 스냅샷만 화면으로 넘겨 대시보드, 트레이 메뉴, 임계치 알림을 갱신합니다.

## 핵심 기능
- 6개 공급자를 같은 형태로 보여 주는 통합 대시보드
- 추정치 없이 실제 usage API 값만 표시하고, 데이터가 없으면 이유를 표시
- 트레이에 남은 사용량 표시, 임계치 알림
- 5시간 창 시작 시점을 맞추는 앵커링(선택)
- 한국어·영어, 로그인 시 자동 실행

## 기술적 포인트
- **보안 불변식**: 비밀 토큰은 Rust 밖으로 나가지 않으며, CSP로 화면의 외부 연결을 막음
- **장애 격리**: 한 공급자의 panic이 앱 전체를 멈추지 않도록 설계
- **테스트**: Rust 테스트 180여 개(모의 서버 기반), 프론트 테스트 파일 27개
- **CI**: lint·타입 검사·테스트, macOS·Windows에서 clippy·cargo test, 태그 푸시 시 macOS universal 빌드

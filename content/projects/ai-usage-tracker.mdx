## 한 줄 소개
Claude, Codex, Gemini, GitHub Copilot, Cursor, z.ai의 실제 구독 사용량을 메뉴바와 대시보드에서 확인하는 macOS/Windows 앱입니다.

토큰 사용량을 추정하지 않고 각 CLI가 로컬에 저장한 인증 정보를 읽어 공급자의 usage API를 직접 호출합니다. 비밀 토큰은 Rust 레이어 밖으로 보내지 않고 UI에는 사용량 정보만 전달합니다.

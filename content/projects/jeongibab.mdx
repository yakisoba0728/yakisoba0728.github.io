## 한 줄 소개
“내 차 밥 먹일 곳 찾기”를 목표로 만든 전기차 충전소 모바일 웹앱(PWA)입니다. 주변 충전소, 충전기별 실시간 상태, 요금, 경로 주변 충전소를 보여 주며 [jeongibab.yaki.kr](https://jeongibab.yaki.kr)에서 운영 중입니다.

## 아키텍처
- **수집 데몬(Python)** — 한국환경공단 API 등 여러 데이터 소스를 계속 수집해 충전기 테이블에 적재하고 충전소 집계를 갱신합니다. 대량 초기 수집용 C 수집기도 따로 만들었습니다.
- **DB** — PostgreSQL + PostGIS(공간 질의), trigram 인덱스(이름·주소 검색)
- **앱(Next.js)** — API는 자체 DB만 조회하고 외부 API를 직접 호출하지 않습니다.
- **운영** — 하나의 Docker 이미지에서 DB, 수집 데몬, 웹 서버를 함께 실행

## 동작 흐름
1. 수집 데몬이 충전기 기본 정보는 계속 순환 수집하고, 상태 변화는 2분마다, 요금은 3시간마다 갱신합니다.
2. 같은 충전기는 갱신 시각이 더 최신인 값만 반영하고, 바뀐 충전소만 집계를 다시 계산합니다.
3. 사용자가 지도를 움직이면 PostGIS 거리 질의로 주변 충전소를 찾습니다.
4. 마커 클러스터와 하단 시트로 결과를 보여 주고, 상세 화면에서 충전기 상태와 예상 요금을 표시합니다.
5. 경로 탭은 서버에서 카카오 경로를 계산하고, 경로 주변 충전소를 진행 순서대로 정렬합니다.

## 핵심 기능
- 주변·영역 재검색, 충전소 이름·주소 검색
- 사용 가능 여부, 급속/완속, 출력, 운영사, 커넥터 필터
- “N시간 M분째 충전 중” 표시와 예상 요금
- 사업자별 회원·비회원·로밍 요금
- 경로 주변 충전소, 카카오맵 길안내 연결, 즐겨찾기, 홈 화면 설치

## 기술적 포인트
- **동시 쓰기**: 잠금 순서를 고정하고 교착이 나면 배치를 재시도
- **보안**: API rate limit, 프록시 뒤 요청 출처 검증, DB TLS
- **테스트·CI**: 테스트 파일 60여 개, lint·타입 검사·단위 테스트·수집기 self-test·빌드 4단계 CI

## 한 줄 소개
macOS에서 Wallpaper Engine 워크샵 프로젝트(scene·영상·웹)를 Metal로 네이티브 재생하는 비공식 호환 런타임이자 메뉴바 앱입니다. 외부 패키지 의존성 없이 Swift와 Apple 프레임워크만으로 만들었습니다.

## 아키텍처
- `WapleCore` — 순수 파서·시뮬레이터: PKG 컨테이너, `.tex`(LZ4·DXT), `.mdl` 메시, GLSL → MSL 셰이더 변환기, 파티클
- `WapleRender` — Metal 2D/3D 씬 렌더러, HDR/LDR bloom, 영상·웹 렌더러, 타입별 렌더러 팩토리
- `WapleLibrary` — 라이브러리 스캔·가져오기·저장
- `WaplePolicy` — 재생 정책 순수 모델(Foundation만 사용해 Linux에서도 빌드·테스트)
- `WapleCompat` — 호환성 스캔과 스냅샷 비교 CLI
- `Waple` — SwiftUI 메뉴바 앱, 스크린세이버(`.saver`)

## 동작 흐름 — 워크샵 항목이 바탕화면이 되기까지
1. Discover 탭에서 사용자 본인의 Steam API 키(Keychain 저장)로 워크샵을 탐색하고 본인의 `steamcmd` 세션으로 내려받습니다.
2. 라이브러리가 폴더를 스캔해 scene·video·web 유형을 판별합니다.
3. 렌더러 팩토리가 유형에 맞는 렌더러를 고릅니다.
4. scene이면 PKG를 풀어 `scene.json`을 해석하고, 셰이더는 전처리(combo·include·매크로)를 거쳐 Metal Shading Language로 변환합니다.
5. Metal로 레이어 블렌드, 파티클, puppet warp, PBR, bloom을 렌더링합니다.
6. 결과를 바탕화면 아이콘 아래 창에 그리며, 모니터마다 다른 배경화면을 지정할 수 있습니다.

## 핵심 기능
- scene 네이티브 렌더링: 3D 메시, puppet warp, 마우스 반응, 파티클, 텍스트, 오디오 반응 효과
- 영상(mp4/mov 직접 재생, webm/mkv 변환)과 오프라인 웹 배경화면
- 재생목록·셔플, 모니터별 배정, 창에 가려지면 자동 일시정지
- 정지 배경화면 설정, 스크린세이버, 로그인 시 자동 실행, 한국어·영어 UI

## Reverse Engineering
Wallpaper Engine 2.8.42를 Ghidra·Frida와 실제 씬 코퍼스로 분석해 PKG/TEX/MDL 포맷과 렌더링 동작을 구현 가능한 수준의 규격으로 정리했습니다.

## 기술적 포인트
- **테스트**: 7개 테스트 타깃, 테스트 함수 4,000여 개. 실제 씬 코퍼스를 쓰는 정답 비교 테스트는 별도로 실행
- **동시성**: Swift strict concurrency 진단을 켜고 CI에서 경고 수를 추적
- **CI**: macOS 러너에서 실행·스킵 수 집계, 병렬 격리 게이트, 서명 단계가 있는 릴리스 워크플로
- 여러 차례 자체 감사를 돌려 결함을 찾아 고치는 방식으로 안정성을 높였습니다.

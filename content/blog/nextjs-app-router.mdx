App Router에서는 `generateStaticParams`로 빌드 타임에 경로를 생성할 수 있습니다.

```tsx
export function generateStaticParams() {
  return getAllPosts().map((p) => ({ slug: p.slug }))
}
```

덕분에 별도 서버 없이도 빠른 정적 페이지를 얻습니다.
